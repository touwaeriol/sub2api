# 计费说明

本平台采用按量计费模式，用多少付多少，没有订阅费。

## 计费方式

费用按 token 用量计算：

| 计费项 | 说明 |
|--------|------|
| 输入 tokens | 你发送给模型的文本 |
| 输出 tokens | 模型生成的回复 |
| 缓存读取 | 命中 prompt cache 的部分（享受折扣） |

不同模型的单价不同，一般来说：
- 模型越大（如 Opus）越贵，但能力越强
- 模型越小（如 Haiku）越便宜，速度也更快

## 查看余额和用量

登录后在「控制台」首页可以看到：
- 当前账户余额
- 近期使用量图表
- 每日消费明细

## 充值

进入「控制台」→「充值」页面，选择充值金额完成支付即可。

## 省钱技巧

### 1. 选择合适的模型

不是所有任务都需要最贵的模型。简单问答用 Haiku，日常编码用 Sonnet，只在复杂推理时用 Opus。

### 2. 善用 prompt cache

对于有大段固定前缀的场景（如系统提示词），prompt cache 可以显著降低输入 token 的费用。

### 3. 控制输出长度

在请求中设置 `max_tokens` 可以限制模型的输出长度，避免不必要的消耗。

### 4. 监控用量

养成定期查看用量报表的习惯，及时发现异常消耗。
