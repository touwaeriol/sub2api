# 常见问题

## 账号相关

### 如何注册账号？

在首页点击「登录」，选择邮箱注册或 Google 登录。

### 忘记密码怎么办？

在登录页面点击「忘记密码」，输入注册邮箱，按照邮件中的指引重置密码。

### 支持哪些登录方式？

- 邮箱 + 密码
- Google 账号登录

## API 使用

### 支持哪些 API 格式？

同时支持两种格式：

- **OpenAI 格式**：`/v1/chat/completions`、`/v1/responses`
- **Anthropic 格式**：`/v1/messages`

你可以使用 OpenAI SDK 或 Anthropic SDK 直接调用，只需要修改 base URL 和 API Key。

### 支持流式输出吗？

支持。在请求中设置 `"stream": true` 即可获得流式响应。

### 返回 401 Unauthorized 错误

- 检查 API Key 是否正确
- 确认 Key 没有被删除
- 检查 `Authorization` header 格式：`Bearer 你的KEY`

### 返回 429 Too Many Requests

你触发了速率限制。稍等片刻后重试，或联系管理员了解限流策略。

### 返回 502 / 503 错误

上游模型服务暂时不可用，通常会自动恢复。如果持续出现请联系管理员。

## 计费相关

### 如何查看消费明细？

登录控制台，在「用量」页面可以查看每日、每周的详细消费记录。

### 余额不足会怎样？

余额为零时 API 请求会返回错误。请及时充值以避免服务中断。

### 支持退款吗？

请联系管理员咨询退款政策。
